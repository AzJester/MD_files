## Formatting

**Bold**, *italic*, ~~strikethrough~~, `inline code`, and <kbd>Ctrl</kbd> + <kbd>K</kbd>.

- Lists nest
  - two spaces per level
    - like this
- [x] Task lists work
- [ ] and show their state

1. Numbered lists
2. keep their order

> [!TIP]
> Callouts use GitHub's syntax, so they render on GitHub too. The types are NOTE, TIP, IMPORTANT, WARNING and CAUTION.

| Shortcut | Action |
|:---------|:-------|
| `Ctrl K` or `/` | Search titles and text |
| `Ctrl E` | Edit or finish editing |
| `Ctrl S` | Save now (it also autosaves) |
| `F3` | Next search match |
